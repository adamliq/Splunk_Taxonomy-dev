Splunk Object Taxonomy

A hierarchical taxonomy of every kind of object that exists across the Splunk universe -- describing what each object is, organised into 13 SOT-01 – SOT-13 domains (each with class → subclass levels down to the object itself), independent of the LATCH TAX-XX taxonomy in index.html. Attributes like scope, config file, dependencies and lifecycle live on the object as properties rather than as branches of the classification -- see the Tree Explorer for the hierarchy, or the Table View for the original flat, filterable catalogue.

Standalone reference, independent of the LATCH taxonomy app (index.html) in this repository — nothing here is wired into TAX-XX codes; the Splunk Object Taxonomy uses its own SOT-01–SOT-13 namespace. Object names, config files and scopes reflect Splunk Enterprise/Cloud platform conventions as of Splunk 9.x/10.x; verify against your specific version's documentation before relying on an exact setting name. Attributes shown as To be confirmed (Owner, Cloud/Enterprise support, Namespace/App, Mutable, Exportable, Security relevance, Configuration layer, Platform) have no derivable value in the current catalogue and are placeholders for future enrichment, not fabricated data.
